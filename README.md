# C Programming

A structured collection of C programming problems created while
learning and strengthening C programming fundamentals.

## Topics Covered

1. C Basics
2. Loops & Patterns
3. Functions & Recursion
4. Arrays
5. Strings
6. Pointers
7. Structures & Unions
8. Dynamic Memory Allocation
9. File Handling
10. Interview-Level Problems

## Learning Goals

- Build strong C programming fundamentals
- Improve problem-solving skills
- Understand memory and pointers
- Practice data structures and algorithms
- Develop programming fundamentals useful for VLSI and digital design
